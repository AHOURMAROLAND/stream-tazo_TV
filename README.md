# TAZO TV 📺

Site d'agrégation de streams de matchs de football en direct.

## Stack
- React 18 + Vite
- TailwindCSS
- Zustand
- hls.js
- Axios + React Router v6

## API
- Matchs : `kora-api.space`
- Streams : `us.meshify.cloud`
- Logos : `cdn.kora-api.space`

## Lancer le projet
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
